# 운영 원본 복원과 잠정 재평가

2026-09-11 KST에 운영 DB를 SELECT로만 조회했다. 가격 기준일은 2026-09-10이다.
운영 데이터 변경, 새 시세 공급 호출, 주문 또는 배포는 수행하지 않았다.

## 원본 연결

사이클 1,444건 모두에 대해 같은 티커·액션·기준가이며 사이클 시작 직전 5초 이내에
생성된 전략이 하나씩 존재했다. 1,444건 모두 연결된 원본 리포트 JSON의 티커·액션·
기준가·목표가·손절가와도 일치했다. 이는 보강된 복원 근거이며, 당시에 저장된 불변
`original_decision` 자체는 아니다. 해당 새 필드가 운영에 이미 있다고 주장하지 않는다.

- 최초 조건과 현재 목표·손절 조건이 다른 사이클: **847건**.
- 저장 상태가 `superseded`인 사이클: **1,011건**.
- 90일보다 오래됐으나 저장된 60일 관측이 없는 사이클: **218건**.
- 운영에 최초 판단 메타데이터가 보존된 사이클: **0건**. 새 코드는 아직 로컬 브랜치다.

## 로컬 재평가 결과

기존 `market_data_cache`에서 84개 티커의 16,698개 관측을 읽고 공급자·캐시 키·마지막
거래일과 함께 별도 입력 파일에 고정했다. 최초 조건으로 만기 안의 목표·손절만 평가하고,
고정 1/5/20/60일 가격 변화는 별도로 계산했다. 입력 SHA-256:

`9183b09988aec8f5bf284968441b3373fd44aca23c162d71771d77606a993cec`

| 분류 | 건수 |
|---|---:|
| 입력 | 1,444 |
| 최초 목표·손절 방향 부적합으로 제외 | 224 |
| 평가 가능(아직 관찰 중인 표본 포함) | 1,220 |
| 최초 목표 도달 | 169 |
| 최초 손절 도달 | 231 |
| 만기 종료 | 715 |
| 관찰 중 | 105 |
| 60일 가격 변화 계산 가능 | 173 |

저장 상태와 다른 종료 결과는 878건이다. 이 중 **801건은 `superseded`를 최초 예측의
결과로 평가한 목적 차이**이므로 기존 코드 오류 건수로 부르면 안 된다. 교체 상태를
제외한 다른 종료 판정은 **77건**이며, 최초 장벽 복원·만기 제한·백필 시점의 영향을
함께 포함한다. 각 원인의 독립적 인과 효과로 나누어 합산할 수 없다.

BUY 추천의 최초 기준가 대비 5일 단순 가격 변화:

| 기간 | 5일 성숙 표본 | 평균 |
|---|---:|---:|
| medium | 188 | -2.5642% |
| short | 446 | -0.8185% |

이 값은 실계좌 수익률·투자 가능한 포트폴리오 수익률·비용 차감 전략 수익률이 아니다.
같은 종목과 같은 날짜 표본이 겹치고, 현재 보유 비중·환율·비용·배당을 반영하지 않았다.
이 결과만으로 매수 후보나 위험 예산을 변경하지 않는다.

## 남는 한계와 다음 단계

1. 최초 방향이 부적합한 224건은 임의로 목표·손절을 뒤집지 않고 제외했다.
2. 기업행사 조정 기준이 별도 버전으로 보존되지 않아 과거 기준가와 캐시 가격의 완전한
   동질성을 보증할 수 없다. 내부 누락 세션 또한 거래소 달력 대조가 필요하다.
3. 일봉과 다음 날짜를 사용하므로 실제 시점의 체결 가능 가격이나 당일 선후 관계를
   복원하지 않는다. 모델 승격은 금지 상태다.
4. 운영 데이터를 덮어쓰려면 이 한계를 해소한 비교 산출물과 백업·복원 절차를 먼저
   검토해야 한다. 이번에는 로컬 재평가만 수행했다.
