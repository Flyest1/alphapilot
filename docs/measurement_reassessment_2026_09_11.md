# 거래 세션·가격 기준 재평가 결과

## 결론

동결한 1,444건을 2026-09-10 기준으로 다시 검토했다. **이번 자료의 주요 관측 공백은
중간 거래일 누락이 아니라 캐시가 오래되어 마지막 날짜 이후 가격이 없는 문제였다.**
재조회로 기존 관찰 중 38건의 결과를 추가 관측했다. 이는 예측력 향상이나 기존 종료
판정 오류 38건을 뜻하지 않는다. 가격 조정 이력의 미보존 때문에 이번 결과도 잠정 연구다.

운영 DB·기존 산출물·추천 조건은 바꾸지 않았다. 신규 조회는 기존 허용 공급자
pykrx와 yfinance만 사용했다. 운영 성과 정정이나 모델 승격에는 사용하지 않는다.

## 1. 세션 목록과 데이터 확보

평가 기간은 2026-06-01~09-10이다. 미국 공식 정규 주식시장 일정과 국내 규칙 기반
잠정 목록을 구분해 고정했다. [달력 출처와 한계](research/session_calendar_2026_06_09.md)를
참조한다. 국내 지수 재조회는 KRX 인증·파싱 문제로 실패해 추가 독립 대조가 미완료다.

재조회는 국내 33개·미국 51개, 총 84개 티커에서 각각 71개 일봉을 확보했다.
`BRK.B` 최초 요청 실패는 기존 운영 코드와 같은 공급자 표기 `BRK-B`로 재시도했다.
실패 응답도 원래 파일에 보존하고 성공 자료는 별도 v2 디렉터리에 저장했다.

가격 공급자 설정:

- 미국: `auto_adjust=False`, `actions=True`, `repair=False`. OHLC와 함께 제공된
  `Adj Close`, 분배금·분할 표시를 원본 증거에 보존했다. `auto_adjust=False`만으로
  과거 분할 조정이 없거나 당시 가격 기준과 일치한다고 보증하지 않는다.
- 국내: `adjusted=True`를 명시했다. 이는 기존 운영 pykrx 호출의 기본값과 같다.
  비수정 가격 및 기업행사 원장은 이번 수집에 없으므로 기업행사 원인 확정은 불가하다.
- 공급자·수집 시각·설정과 각 증거 파일의 SHA-256을 기록했다.

달력 대조는 추천 다음 날짜부터 기준일까지 **전체 관측 구간**의 완전성을 요구한다.
목표를 이미 맞힌 추천도 이후 20/60일 관측이 불완전하면 보수적으로 행 전체를 제외한다.
따라서 이 도구의 평가 가능 건수는 목표·손절 판정만 가능한 건수와 다를 수 있다.

기존 캐시에서 세션 부족으로 제외된 795건은 모두 마지막 시세 이후의 공백이었다.
국내 64건, 미국 731건이며, 이번 범위에서 내부 누락은 발견하지 못했다.
달력 검사가 장벽 검사보다 먼저 실행되므로, 제외 사유 795건과 최초 장벽 부적합
224건은 단순 합산하면 안 된다. 이 중 120건은 두 조건이 겹친다.

달력을 통과한 공통 545건의 목표·손절·만기 상태 변화는 0건이다. 다만 15건은
1/5/20/60일 가격 변화 값 중 하나 이상이 달라졌다.
기존 달력 미대조 평가와 재조회 평가의 공통 1,220건에서는 관찰 중 38건만 새로 종료됐다.
만기 21건, 목표 13건, 손절 4건이다. 이미 종료된 상태끼리 바뀐 사례는 없었다.

## 3. 가격 차이와 기업행사 증거

동일 날짜 5,796개 가격 행을 대조했다. 절대·상대 오차 허용치는 각각 `1e-6`이다.
OHLC 중 하나 이상이 다른 행은 97개, 종가가 다른 행은 95개(41개 티커)다.

- `475380`: 종가 55개가 다르다. 6/1~8/19의 재조회 종가가 대체로 약 0.29% 낮다.
  일정한 비율의 변경은 가격 조정과 부합할 수 있지만, 기업행사 원장 없이 분배금이나
  특정 사건의 영향으로 확정하지 않는다. 해당 티커 추천은 14건이다.
- 나머지 차이는 대부분 기존 캐시의 최근 일봉에 집중됐다. 장중 일봉이 종가 확정 전
  저장됐을 가능성과 공급자 정정 가능성이 있으며, 이번 대조만으로 원인을 확정하지 않는다.
- 미국 분배금 표시 43건과 `CLBK`의 7/21 분할 표시(2.2)를 보존했다. CLBK 추천은
  9/8 시작 1건이므로, 그 분할이 해당 추천 기간을 가로질렀다고 해석하지 않는다.

현재 운영 표준화 경로는 OHLCV만 남기고 `Adj Close`와 기업행사 열을 제거한다.
기존 캐시의 조정 기준·기준시점도 별도 버전으로 남지 않았다. 따라서 재조회 가격이
원래 추천의 기준가·목표가·손절가와 같은 단위를 유지하는지 **인증한 표본 수는 0건**이다.
재조회 시나리오의 1,220건은 조건부 계산 가능 건수이며, 검증된 실계좌 성과가 아니다.

## 4. 재현과 보존

```powershell
backend/.venv/Scripts/python.exe scripts/reassess_measurement.py `
  backups/profitability_2026_09_11/audit_input.json `
  --evidence-dir backups/profitability_2026_09_11/revision_evidence_v2 `
  --calendar-manifest docs/research/session_calendar_2026_06_09.json `
  --as-of 2026-09-10 `
  --output-dir backups/profitability_2026_09_11/session_price_reassessment_new
```

새 출력 디렉터리를 지정해야 한다. DB나 외부 서비스 연결 없이 동결된 파일만 사용한다.
수집 스크립트와 원시 증거는 기존 Git 제외 경로에 보존했다. 결과 파일:

- `archived_unchecked.json`: 기존 방식 잠정 평가.
- `archived_calendar.json`: 기존 가격의 세션 완전성 검사 포함.
- `refreshed_calendar.json`: 재조회 가격으로 바꾼 민감도 분석.
- `price_comparisons.json`: 가격 차이와 기업행사 표시, 공급자 요청 정보.
- `lineage.json`: 원본·달력·개별 시세 증거 해시와 검증 한계.

원본 입력 SHA-256:
`9183b09988aec8f5bf284968441b3373fd44aca23c162d71771d77606a993cec`

달력 입력 SHA-256:
`080e090462827529c15d58600b9a966a7334025b44b2d46662b3201c9a650706`

## 5. 완료 범위와 남은 일

거래일·가격 비교 도구, 실제 자료 재조회, 비파괴 재평가와 차이 분류를 완료했다.
백엔드 631개 테스트와 Ruff·Black 검사를 통과했다. 이번 도구는 운영 요청 경로에서
호출하지 않는다. 새로운 거래 코드나 DB 마이그레이션은 없다.

측정 신뢰성 확보 전체는 아직 완료가 아니다. 다음 순서를 권한다.

1. 앞으로 생성되는 입력에 가격 조정 기준·공급자 버전·기업행사·완료 세션 여부를 보존한다.
   이미 제거된 과거 이력을 현재 설정값으로 거꾸로 채우지 않는다.
2. 국내 실제 시장 달력의 추가 확인 및 `475380`의 가격 조정 원인 대조를 마친다.
3. 실제 계좌 현금흐름 원장 설계로 넘어가 가격 수익·분배금·환율·비용을 분리한다.
   과거 추천 수익률을 계좌 운용 수익률로 대체하지 않는다.
