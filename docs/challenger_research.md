# 고정 가설 연구 비교 실행기

이 실행기는 로컬 일별 OHLCV JSON을 읽어 고정 가설의 기술 규칙을 비교합니다. 운영 설정,
데이터베이스, 추천, 주문을 변경하지 않으며 네트워크를 사용하지 않습니다.

```powershell
python scripts/run_challenger_research.py input.json --output comparison.json
```

출력 경로는 새 파일이어야 합니다. 기존 파일과 입력 파일을 덮어쓰지 않습니다.

입력 형식은 다음과 같습니다. `prices`에는 예시 한 행 대신 충분한 일별 이력이 필요합니다.
시장값은 `KR` 또는 `US`를 명시하며, ETF도 실제 상장 시장을 이 필드에 기록합니다.

```json
{
  "as_of": "2026-09-10",
  "costs": {
    "fee_rate_pct": 0.1,
    "kr_tax_rate_pct": 0.2,
    "fx_spread_pct": 0.1
  },
  "price_provenance": {
    "provider": "공급자명",
    "retrieved_at": "조회 시각",
    "adjustment_basis": "가격 조정 기준",
    "currency": "USD"
  },
  "assets": [
    {
      "ticker": "AAPL",
      "market": "US",
      "prices": [
        {"date": "2020-01-02", "open": 100, "high": 102,
         "low": 99, "close": 101, "volume": 1000000}
      ]
    }
  ]
}
```

비용 예시는 설정 형식 설명용이며 실제 요율을 보증하지 않습니다. 수수료와 환전비는
편도 백분율, 국내 거래세는 매도 한 번의 백분율입니다. 기존 비용 함수의 유동성 미확인
기본 슬리피지를 더합니다. 비용 2배 실험은 모든 비용 항목을 함께 두 배로 적용합니다.

비교 대상은 네 가지이며 비용 1배/2배, 추가 지연 0/1거래일을 모두 실행해 16개 결과를 남깁니다.

- 챔피언: 소스 SHA-256으로 고정한 현재 기술 점수와 `balanced` 규칙의 BUY만 참여합니다.
- 추세 필터: 챔피언 BUY 중 종가가 SMA120 위이고 고변동성 구간이 아닌 경우만 참여합니다.
- 진입·유지 구분: 매일 점수 80 이상에서 참여 상태를 시작하고 65 미만에서 종료합니다.
- 단순 보유 비교: 같은 시작일과 비용으로 20거래일 보유하며 목표·손절 장벽을 사용하지 않습니다.

이는 운영 위험 성향을 변경하거나 운영 챔피언 성과를 그대로 재현하는 실행기가 아닙니다.
SELL/REDUCE의 회피 손실을 공매도 수익으로 계산하지 않습니다. 유지 상태는 다음 연구 표본의
참여 여부이며 표본 간 실제 포지션을 이어 보유하는 시뮬레이션이 아닙니다.

각 결정은 120거래일 이후 22거래일 간격으로 생성합니다. 결정 당시 종가와 ATR로 장벽을
고정한 뒤 다음 거래일 시가에 진입하고 20거래일을 평가합니다. 지연 실험은 한 거래일 더
늦게 진입합니다. 진입 시가가 기존 장벽 밖이면 제외하고, 같은 날 양쪽 장벽이 닿으면
손절 쪽을 사용합니다. 손절 갭은 시가와 손절가 중 불리한 가격을 사용합니다.

워크포워드 구간은 최초 학습 진단 6개 결정일, 격리 1개 결정일, 평가 3개 결정일로
고정하며 과거 진단 구간만 확장합니다. 같은 결정일의 모든 자산은 가장 늦은 평가 종료일로
묶어 경계에서 제거합니다. 학습은 진단이라는 뜻이며 모델 적합이나 임계값 탐색은 하지 않습니다.
첫 표본에는 최소 142행, 한 시장에서 첫 평가 구간에는 대략 339행이 필요합니다.

출력에는 모든 실험의 개별 관측, 제외 사유, 학습 진단/평가 구간, 유효 결정일 수,
챔피언과 공통으로 평가 가능한 자산·날짜의 평균 차이가 들어갑니다. 모든 실험의 공통 비교
결정일이 최소 30개이고 평가 구간이 최소 3개여도 설명적 비교만 제공하며 우월성이나 승격을
판정하지 않습니다. 입력·설정·관련 소스 해시를 함께 기록하고 챔피언 소스가 바뀌면 중단합니다.

서로 떨어진 표본의 평균을 보여주며 연환산·복리·실제 계좌 수익률을 계산하지 않습니다.
유니버스 생존편향, 장중 체결, 시장별 휴장 및 중간 누락 거래일, 가격 조정·통화 기준은
별도의 증거 검증이 필요합니다. 제외로 인한 표본 변경은 원시 평균과 공통 비교를 함께 읽어야 합니다.
