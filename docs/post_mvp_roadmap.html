AlphaPilot Post-MVP

개인 투자 운영 시스템 로드맵

MVP는 완료되었고, 다음 단계는 리포트 생성 도구를 안정적인 투자 운영 시스템으로 발전시키는 것입니다. 핵심은 데이터 신뢰도, 성과 검증, 포트폴리오 의사결정, 모바일 사용성, 보안 수준을 단계적으로 끌어올리는 것입니다.

제품 방향

AlphaPilot은 단순 리포트 생성기를 넘어, 매일 포트폴리오 상태를 점검하고 추천의 성과를 추적하며 리스크를 관리하는 개인 투자 운영 시스템으로 발전합니다. 

Return optimization = expected return * probability of success - downside risk - volatility risk - concentration risk - liquidity risk
모든 기능은 투자 의사결정 지원용입니다. 자동매매, 브로커 API, 주문 실행, 주문 미리보기, 거래 스텁은 구현하지 않습니다.

현재 MVP 기준선

구현 완료

  • GitHub Pages React 프론트엔드
  • Render Free FastAPI 백엔드
  • Supabase PostgreSQL 저장소
  • GitHub Actions 정기 리포트 호출
  • OpenAI 구조화 리포트 생성
  • 기술 지표 기반 fallback 리포트
  • pykrx, yfinance 시장 데이터
  • GDELT 뉴스/동향 컨텍스트

운영 중 기능

  • 자산 CRUD
  • 보유 외 후보 관리
  • 대시보드 차트
  • 비동기 수동 리포트 생성
  • 국내/글로벌 정기 리포트
  • 전략 상세/후보 탭
  • 성과 로그 backfill
  • 단일 사용자 토큰 게이트

단계별 로드맵

Phase 1

운영 안정화

리포트 생성 상태와 실패 원인을 추적 가능하게 만듭니다.

  • report_jobs Supabase 테이블
  • 작업 단계별 소요시간 기록
  • 안전한 실패 원인 분류
  • Status 화면에서 생성 상태 표시
Phase 2

포트폴리오 스냅샷

대시보드 장기 차트를 실제 저장 이력 기반으로 바꿉니다.

  • portfolio_snapshots 테이블
  • 일별 총 평가금액, 손익, 현금, 배분 저장
  • 7일/1달/3달 추이 표시
Phase 3

추천 생애주기 추적

추천이 반복되어도 성과가 초기화되지 않도록 추천 단위를 분리합니다.

  • recommendation_cycles 테이블 설계
  • 목표가/손절가/만료/성공/실패 상태 추적
  • 1일, 5일, 20일, 60일 성과 검증
Phase 4

분석 품질 강화

추천 근거를 더 투명하게 만들고 데이터 품질을 표시합니다.

  • 신뢰도 산정 근거 표시
  • 기술/뉴스/포트폴리오 기여도 분해
  • 섹터, 국가, 통화, 집중도 위험 표시
  • 리포트 입력 스냅샷 저장 검토
Phase 5

포트폴리오 의사결정 지원

실행이 아니라 판단을 돕는 리밸런싱과 현금 운용 제안을 추가합니다.

  • 목표 비중 설정
  • 리밸런싱 제안
  • 현금 투입 후보
  • 매도/축소 관찰 목록
Phase 6

모바일 UX 개선

매일 휴대폰으로 확인하기 편한 화면 흐름으로 다듬습니다.

  • 모바일 리포트 카드
  • 빠른 요약 홈
  • 캐시 기반 첫 화면 속도 개선
  • PWA 설치 지원 검토
Phase 7

보안 강화 결정

사용자가 보안 모델을 선택한 뒤 구현합니다.

  • A. 현재 단일 사용자 토큰 유지
  • B. 서버-side 비밀번호/세션
  • C. Supabase Auth

개발 순서

  1. AGENTS.md와 HTML 로드맵 문서 업데이트
  2. report_jobs DB 저장 방식으로 변경
  3. 리포트 생성 단계별 시간/상태 UI 추가
  4. portfolio_snapshots 추가
  5. 대시보드 히스토리를 스냅샷 기반으로 변경
  6. 추천 생애주기 테이블 설계 및 구현
  7. 기존 performance_logs와 연결 또는 이전
  8. 신뢰도/데이터 품질 설명 강화
  9. 포트폴리오 의사결정 지원 기능 추가
  10. 모바일 UX 개선
  11. 보안 모델 결정 후 적용

승인이 필요한 결정

영역 결정 필요 내용 이유
DB 스키마 report_jobs, portfolio_snapshots, recommendation_cycles 새 테이블은 데이터 구조와 API 계약에 영향을 줍니다.
보안 토큰 유지, 서버 세션, Supabase Auth 중 선택 인증 방식은 공개 API와 사용자 경험을 바꿉니다.
외부 서비스 알림, 유료 데이터, 새 LLM, 외부 cron AGENTS.md whitelist 업데이트가 필요합니다.
스케줄 스냅샷 생성 시점 리포트 생성 시점만 저장할지, 대시보드 조회 시에도 저장할지 결정해야 합니다.
