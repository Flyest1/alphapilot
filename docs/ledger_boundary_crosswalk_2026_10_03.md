# 미결제 경계·종목 코드 대조 묶음 (2026-10-03)

결제기준 증명서와 체결기준 원장 사이의 미결제 연결을 검토할 거래 목록,
증명서 종목 코드와 거래내역서 코드의 대응 후보를 만들었다.
공식 날짜·시간대·코드 대응 설명은 아직 없으므로 확정 원장 입력을 만들지는 않았다.

## 원문 코드 대응과 수량 관측

증명서의 73행마다 원본 해시·페이지·보유 행 번호를 유지하고, 네 거래내역서의
매매 행에서 추출한 원문 코드와 비교했다. 코드가 같더라도 실제 거래 티커·시장
대응을 공식 확인한 것으로 승격하지 않았다.

국내 코드가 같은 10행 중 기초 4행은 기준일 이전 매매 관측이 없어 수량을
비교할 수 없었다. 나머지 기초 3행과 기말 3행은 기준일 이하 가장 최근 표시 날짜의
매매 잔고 수량이 증명서 수량과 일치했다. 같은 날짜가 여러 문서에 있다면 각 문서의
마지막 관측값을 보존해 값 충돌을 검사한다. 이 여섯 행에는 값 충돌이 없었다.
현금 대조와 마찬가지로 PDF 표시 날짜의 경제적 의미는 여전히 미확정이다.
마지막 매매 이후의 이관·권리 변동·미결제 변화까지 검증한 것은 아니다.

해외 보유 행 47개의 13자리 원문 코드가 거래내역서의 12자리 ISIN으로 시작하는지
문자열 관계만 검사했지만 일치하는 후보는 없었다. 끝자리 하나를 제외하면 ISIN이
된다는 가정을 현재 자료가 뒷받침하지 않는다. 이 결과를 일반적인 코드 변환 규칙으로
확장하지 않고, 원문 코드를 그대로 보존했다. 이름이나 수량으로 티커를 확정하지 않았다.
국내에서도 같은 코드가 없는 16행은 보유 기간 중 매매가 없었을 수 있으므로
잘못된 코드·누락 거래라고 단정하지 않는다.

비공개 최신 출력:

- `review_v2/certificate_statement_code_candidates.csv`: 증명서 73행의 코드 관계와 거래행 출처.
- `review_v2/exact_code_quantity_observations.csv`: 같은 원문 코드의 수량 비교, 비교 불가 사유와 출처.
- 모든 `ticker_confirmed`, `operating_import_allowed`, `full_position_reconciled`는 false.

이 날짜 구간은 현재 제공된 자료로 확인할 경계를 정한 것이며 결제 주기 규칙이나
전체 미결제 범위의 충분성을 확정하지 않는다. 수는 구매·판매의 PDF 관측 행이며
서로 다른 실제 체결 수 인증이 아니다. 10월 2일 발급 자료도 그날 전체 마감 증거는 아니다.

`review_v2/boundary_trade_observations.csv`에는 89개 출처 좌표, 매매 구분·통화·
원문 코드·PDF 날짜와 증명서 기준일의 전후 관계를 연결했다. 체결 시각과 실제
결제일은 빈 값, 기준일 미결제 여부는 모두 `unknown`이다. 9월 29일 구매 화면과
10월 1일 PDF의 아홉 수량 후보는 [날짜 기준 대조](ledger_date_basis_2026_10_03.md)를
참조하며, 구매 완료·출금 예정·실제 결제를 구분한다.

원장의 결제 전 매수는 체결 수량과 미지급 대금을, 매도는 수량 감소와 미수 대금을
별도로 반영한다. 따라서 결제기준 증명서에 없는 거래를 없었던 것으로 처리하거나
부족한 미수·미지급을 0으로 채우지 않았다. 외부 자금 흐름도 임의로 생성하지 않았다.

## 다음 확인과 검증

고객센터 답변 또는 별도 원문에서 거래 유형별 날짜 정의·시간대·마감 기준,
두 기준일 미결제 내역의 체결 일시·실제 결제일·대금·수량·주문 식별자를 확인해야 한다.
해외 13자리 코드와 ISIN·해당 시점 거래 티커의 공식 대응도 필요하다.
이를 확보하면 현재 후보표의 출처를 유지하며 확인한 항목만 확정할 수 있다.
이 작업에서 고객센터에 메시지를 보내거나 계좌 API를 호출하지 않았다.

여섯 PDF 해시를 재검사하고 73개 행의 유일성, 10개 동일 코드 관계,
여섯 수량의 독립 pdfplumber 원문 셀 일치, 경계 89행의 출처 유일성,
미확정 항목이 확정·운영 입력으로 승격되지 않았음을 검사했다.
최종 검증과 산출물 해시는 `verification/report.json`에 있다.
초기 `review`는 선택한 경계 PDF 안에서만 수량을 비교한 결과이며,
`review_v2`는 네 PDF의 기준일 이전 관측까지 비교 범위를 넓힌 최신 결과다.
기존 출력은 보존했다.

명세서·중복·매핑 검토와 준비 서비스·CLI의 관련 회귀 테스트 52개가 통과했다.
제품 코드 변경이 없어 전체
백엔드·프론트엔드 검증과 운영 배포는 새로 실행하지 않았다.
`coverage_verified=false`, `stored=false`, `account_balance_reconciled=false`,
수익률 미검증 상태다.
